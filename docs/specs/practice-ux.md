# 历练玩法与战斗演出规格

状态：已落地第一版

## 1. 玩家心智模型

历练不是四个互相独立的页面，而是一条每天重复的战斗循环：

```text
演武补兵/看克制
  -> 秘境验证编队、领取首通资源、解锁修士
  -> 远征消耗行动令、选择路线、兑换远征币与遗物
  -> 修士强化主力兵种
  -> 回到演武，准备下一次出征
```

入口顶部固定展示这条循环，并在当前页同时回答“做什么、为什么做、能得到什么、下一步去哪”。详细顺序放在可收起的每日顺序中，避免教程只覆盖开局几分钟。

## 2. 导航层级

底部四个入口是同级主页面，不再把“历练”和“宗门”实现成覆盖底栏的模态弹层：

- `洞府`：资源、建筑、寻道和当前道途，保留场景点击作为核心交互。
- `历练`：进入后由顶部玩法总览切换演武、秘境、远征、修士；总览卡同时承担用途说明和内部导航，避免重复出现两套页签。
- `战区`：整页承载共享地图和派兵命令；排行榜、征募、战报、好友和聊天属于战区上下文。
- `宗门`：整页承载合围妖兽、建造队列和宗门身份管理；创建/加入宗门不再隐藏在战区排行榜内。

建筑详情、道途指南、突破、好友和战区排行榜仍使用模态弹层。模态层覆盖底部导航，页面内容自身滚动，并给底部留出安全区，避免最后一个操作被导航截断。

## 3. 四个入口的职责

| 入口 | 玩家要做什么 | 核心产出 | 失败/代价 | 下一步 |
| --- | --- | --- | --- | --- |
| 演武 | 训练三类部队、按敌方兵种调整编队 | 部队、统兵名额、克制战力 | 训练消耗资源 | 去秘境看敌阵 |
| 秘境 | 逐关挑战章节 PvE | 首通资源、章节进度、关键关修士 | 胜败均有兵损；失败不推进、不发首通奖励 | 补兵或挑战下一关 |
| 远征 | 每天在五层路线中二选一 | 远征积分、远征币、28 天游历遗物 | 消耗远征令；失败保留节点并支付兵损/行动令 | 去战绩兑换长期收益 |
| 修士 | 升级对应兵种的专精修士 | 对应兵种永久战力乘区 | 消耗养成资源 | 回演武调整主力流派 |

修士不是独立上阵单位。`cultivatorBonus` 仍由领域层参与 `battlePower`，所以秘境、远征和战区使用同一份增益，UI 只负责解释和展示。

## 4. 战斗演出边界

`src/ui/PracticeBattleScene.tsx` 是秘境与远征共用的表现层。它只接受已经由 `store` 结算的快照：

- 我方/敌方战力、兵种、出战数量和兵损；
- 胜负结果；
- 当前编队快照，避免结算后兵损改变画面中的出战构成。

四幕节奏固定为：

1. 列阵：显示双方立绘、阵线血条和当前战力。
2. 我方动作：根据兵种克制关系显示“克制突击”或“正面冲阵”，血条下降并出现冲击光线。
3. 敌方反击：显示实际兵损，受击抖动、阵线血条变化。
4. 结局：胜利击破敌方阵眼，失败收拢撤离；演出完成后才出现结算卡。

跳过演出只跳过表现，不跳过领域结算。未来接服务端时，服务端返回同形状报告即可复用，不允许客户端根据动画重新计算胜负。

## 5. 远征路线解释

- 破阵：战斗节点，拿积分和资源，失败会损兵并停在当前层。
- 采灵：低风险资源节点，压榨路线可能带回更多资源。
- 护送：中风险资源与积分节点，适合稳妥推进。
- 天机：随机收益节点，压榨失败不推进且浪费本次行动令。
- 首领：第五层终点，提供当日最高收益，出发前应补兵并检查克制。

“稳妥推进”保证成功推进并降低兵损；“压榨路线”提升成功时的奖励、积分和远征币，但失败不推进。路线节点、行动令、积分和远征币都继续由 `src/game/expedition.ts` 与 `src/game/store.ts` 的领域规则维护，文案不会改变数值。

## 6. 兼容与迁移

- 新 UI 不增加 `GameState` 必填字段；秘境演出所需的 `formation` 快照由挑战返回值即时生成，不写入存档。
- 旧存档仍由 `loadState` 的默认合并逻辑补齐远征、修士和引导字段。
- CSS 动效只使用 `transform`、`opacity`、`filter` 和血条宽度过渡；`prefers-reduced-motion` 下保留状态变化但关闭循环动画。
- 服务端正式化时，保留 `ExpeditionReport` 与战区/秘境同样的“领域快照 → 表现层重演”边界，客户端不提交战力结果。
